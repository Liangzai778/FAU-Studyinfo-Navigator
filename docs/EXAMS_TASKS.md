# P5 考试、个人学习任务与本地备份

## 1. 实现边界

P5 只处理用户自行录入的考试与学习任务，不包含 FAU 官方考试清单、报名窗口、自动联网更新或 Campo 操作。所有个人考试固定带有 `origin: personal` 和 `dateStatus: user_entered`；报名状态只表示用户手动记录。

## 2. 数据模型

`PersonalExam` 保存名称、可选课程 ID、开始/结束时间、地点、备注和手动报名状态。`StudyTask` 保存名称、可选课程 ID、截止时间、备注和完成状态。两类记录均带本地 ID、创建/更新时间和固定 `Europe/Berlin` 时区。

课程关联是软链接：只能从当前课程计划中选择，但删除课程不会删除考试或任务。失效链接在界面显示为“原关联课程已不存在”，从而避免连带丢失个人记录。

## 3. Berlin 日期语义

- 表单值按 `YYYY-MM-DDTHH:mm` 的 Berlin 墙钟时间保存，不按访问设备时区改写。
- 无效日历日期和春季夏令时切换中不存在的时刻会被 Zod 拒绝。
- 秋季切换中的重复时刻允许保存，但界面提示用户在导出的日历应用中核对。
- 正式日期模型支持 `confirmed | tentative | unknown`，但生产数据包目前没有正式日期记录。

## 4. IndexedDB

数据库 `fau-study-navigator` 升级为 v3，新增：

- `personal-exams`
- `study-tasks`

考试与任务快照先通过 Zod 校验，再在同一个 `readwrite` 事务中写入。升级只创建缺失对象仓库，不清空 v1/v2 数据。

## 5. ICS 导出

ICS 在浏览器内存中生成并直接下载，不访问网络。输出包含 Europe/Berlin `VTIMEZONE`、CRLF 换行、文本转义及基于本地记录 ID 的稳定 UID。同一 ID 只导出一次；文件不会声称个人考试已官方确认。

## 6. JSON 备份与恢复

备份包为 schema v1，包含应用标识、应用版本、导出时间、学业范围、课程/重修记录、考试和任务。导入文件最大 2 MiB，并检查 JSON、危险对象键、最大嵌套深度、Zod 结构和版本。

恢复前需要用户确认。写入时：

1. 按稳定 ID 合并现有和导入记录。
2. 相同 ID 且内容一致时去重。
3. 相同 ID 但内容不同时拒绝整个恢复。
4. 当前学业范围优先保留；仅在当前为空时采用备份值。
5. 五个 IndexedDB 对象仓库在单事务中更新，失败则整体回滚。

语言、主题、资源收藏和个人网站当前不进入 P5 备份；完整导出和彻底清空仍属于后续数据治理工作。

## 7. 验证范围

自动测试使用显式 `synthetic-test-only`/`Synthetic test` 数据，覆盖 Berlin DST 边界、ICS 时区/转义/去重、IndexedDB 保存恢复、无效写入保护、备份版本和结构拒绝、备份往返及同 ID 冲突保护。测试数据不会显示为 FAU 官方资料。
