# 使用指南

> 在线地址：https://fau-studyinfo-navigator.pages.dev
> 开源地址：https://github.com/tommy2345-art/FAU-Studyinfo-Navigator
>
> 这是一个独立学生工具，与 FAU 没有官方隶属关系。考试报名、成绩和毕业要求以 FAU 官方文件和 Campo 为准。

第一次用，按下面五步就够了。所有数据只保存在你自己的浏览器里。

---

## 1. 打开网站

手机、平板、电脑都可以，直接访问：

**https://fau-studyinfo-navigator.pages.dev**

不用注册，不用登录，也不会读取你的 FAU 账号。

![首页](screenshots/dashboard.png)

---

## 2. 选专业和 PO（最重要的一步）

进入左侧「专业要求」，依次选择：

1. **学位类型**：目前数据只有硕士（Master）
2. **学院**：自然科学学院
3. **专业**：细胞与分子生物学 / 整合生命科学 / 整合免疫学
4. **入学年份 + 学期**：按你实际入学的时间填
5. **PO 版本**：系统只列出候选版本，**不会替你自动选最新版**

选好后勾选「我已在 Campo 的 Studienservice → Meine Studiengänge 中核对此 PO 版本」，再点「保存专业与 PO」。

![专业要求](screenshots/degree-rules.png)

保存后往下滑，就是规则详情：每个要求组多少 ECTS、包含哪些模块、模块在哪个学期开课，每张卡片底部都有官方来源可以点开核对。

> 不知道自己的 PO 版本？先去 Campo → Studienservice → Meine Studiengänge 看一下，再回来选。

---

## 3. 添加课程

进入「学期规划」：

- **从目录选**：搜索模块名或编号，选课程、学期、要求组；
- **手动录入**：勾选「手动录入其他课程」，填课程名、ECTS、学期，再选星期和上课时间。

周一到周五可以选多天，每天的时间可以不同。完成后点「添加到计划」。

添加后可以修改学习状态：

| 状态 | 含义 |
|---|---|
| 计划 | 打算修 |
| 修读中 | 这学期在上 |
| 已通过 | 拿到学分 |
| 未通过 | 没过，之后可以加重修 |
| 已认定 | 交换/认定学分，需要你确认 |

页面上方会显示已完成、可计入当前 PO、计划中学分，以及还缺什么。**规则不完整时结论会显示「无法判断」，不会假装你已满足毕业条件。**

![课程表与日历](screenshots/calendar.png)

---

## 4. 看课程表和学期日历

「学期规划」页往下有：

- **每周课程表**：08:00–21:00，按开始时间摆放，同一天冲突会高亮；
- **学期日历**：月 / 周 / 日三种视图，按 FAU 官方校历的**授课周**显示课程。周末、法定节假日、圣诞/复活节停课日不会排课，第 1 周从授课开始日算起。

日历右侧可以添加你自己的安排：事由、日期、开始/结束时间、备注。过去的安排会收在「已过去的日程」，不会消失。

> 官方校历目前覆盖 SS 2026 至 WS 2027/28；之后的学期按章程规则推算，界面会标注「按章程推算」。

---

## 5. 考试、任务和校园导航

- **考试与期限**：记录考试时间、报名状态、地点和备注；可以生成 ICS 日历文件导入手机日历。
- **校园导航**：30 个官方入口，7 个分类，含国际学生专区（奖学金、Buddy 项目、Welcome Week 等），可按截止日期排序。
- 所有外链都要你自己点击才会打开，应用不会在后台访问任何网站。

![国际学生资源](screenshots/resources-international.png)

## 备份与数据安全

进入「设置」：

- **导出 JSON 备份**：包含专业选择、课程、考试、任务和个人日程；
- **恢复**：按 ID 合并，冲突会拒绝，不会静默覆盖；
- **持久化与自动保存**：可以请求浏览器授予持久化存储，降低空间不足时被清理的概率；
- **数据自检**：如果某条旧记录暂时读不出来，会提示你，但原始数据仍保留，不会被删除；
- **彻底清空**：需要二次确认，清空后无法恢复。

> 数据只存在当前浏览器。换设备、换浏览器或清除站点数据都会看不到；请定期导出备份。
> 两个标签页同时编辑不会互相覆盖；同一条记录同时修改时是后写覆盖。

## 常见问题

**问：为什么只有三个生物专业？**
这三个专业的要求已经对照官方考试条例和模块手册逐条转录、并经过人工核对。其他学院还没有录入，页面会明确显示为空，而不是编造规则。欢迎按贡献指南补上你所在学院的数据。

**问：选专业时看不到我的专业？**
当前版本的覆盖范围只有自然科学学院生物系的三个硕士专业。可以先在「校园导航」里找到官方入口，或者在 GitHub 提「我的学院缺失」issue。

**问：数据会不会上传？**
不会。应用没有后端、没有账号、没有分析工具，也没有后台网络请求。个人数据只写浏览器的 IndexedDB / localStorage。

**问：换电脑/手机怎么办？**
在旧设备导出 JSON 备份，在新设备导入。备份不包含语言、主题和资源收藏。

**问：PO 选错了怎么办？**
回到「专业要求」重新选择并保存。课程记录不会因为换 PO 被删除，但只有与当前 PO 一致的课程会计入毕业学分。
